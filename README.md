# Catania Vice 6

Open world 3D in stile GTA ambientato a Catania, costruito sulla **mappa reale** della città
(strade, piazze, palazzi, porto e ville da OpenStreetMap, licenza ODbL).

- In gioco: guida, missioni di mafia, polizia con livelli di ricercato, pistola, soldi.
- Comandi: WASD/frecce, E per salire o scendere dall'auto, F spara, R ricarica, Shift corri.
- Controller: stick sinistro per guidare, RT accelera, LT frena, A scendi/sali, X spara.
- Su Android: apri il link e usa "Aggiungi alla schermata Home" per giocarlo a schermo intero.

Dati mappa: © OpenStreetMap contributors, ODbL.
